# Real-World Data Project: Retail Sales Analysis and Prediction

## Overview

This project focuses on analyzing a real-world retail sales dataset and building a machine learning model to predict sales based on various business factors. The project demonstrates the complete data science workflow, including data exploration, visualization, statistical analysis, predictive modeling, and business insight generation.

## Objective

The main objectives of this project are:

* Analyze retail sales data to identify business trends
* Explore relationships between sales, price, quantity, and discounts
* Visualize sales performance across product categories
* Build a machine learning model for sales prediction
* Generate actionable business insights from data

## Domain

Retail Industry

Retail analytics helps businesses understand customer purchasing behavior, optimize pricing strategies, improve inventory management, and increase revenue through data-driven decision-making.

## Dataset Description

The dataset contains retail transaction records with the following attributes:

* Order ID
* Product Name
* Product Category
* Product Price
* Quantity Sold
* Discount Percentage
* Total Sales

The dataset represents sales transactions from multiple product categories such as Electronics, Fashion, and Grocery.

* Product Price
* Quantity Sold
* Discount Percentage

The model learned relationships between input features and sales values to generate future predictions.
